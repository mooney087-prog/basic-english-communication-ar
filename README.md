# Udon Thani Expo English AR Game

เกมเว็บสำหรับนักเรียนชั้นมัธยมศึกษาปีที่ 3 ฝึกคำศัพท์ก่อนเรียงประโยคภาษาอังกฤษเกี่ยวกับงานมหกรรมพืชสวนโลกอุดรธานี 2569

## วิธีนำขึ้น GitHub Pages

1. สร้าง Repository ใหม่ใน GitHub
2. อัปโหลด `index.html`, `README.md` และโฟลเดอร์ `images` โดยคงชื่อไฟล์เดิม
3. เปิด Settings > Pages
4. เลือก Deploy from a branch, สาขา `main` และโฟลเดอร์ `/ (root)`
5. กด Save แล้วรอ GitHub แสดงลิงก์เกม

## การใช้งานบนมือถือและแท็บเล็ต

- เปิดผ่าน Chrome บน Android หรือ Safari บน iPhone/iPad
- อนุญาตการใช้ไมโครโฟนเมื่อต้องการตรวจคำพูด
- กด “เปิดกล้องหน้า” แล้วอนุญาตการใช้กล้องและไมโครโฟน
- กด “เริ่มบันทึก” เมื่อต้องการบันทึกวิดีโอการฝึกพูด และกด “หยุดบันทึก” เมื่อเสร็จ
- กด “ดาวน์โหลดวิดีโอ” เพื่อบันทึกไฟล์ไว้ในอุปกรณ์ วิดีโอจะไม่ถูกส่งขึ้นระบบอัตโนมัติ
- ถ้าอุปกรณ์ไม่รองรับการตรวจเสียง ให้พูดตามแล้วกด “ฉันฝึกพูดแล้ว”
